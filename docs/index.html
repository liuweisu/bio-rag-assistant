Bio RAG assistant

Ask about genome assembly, transposable elements, RNA-seq, proteomics, image analysis or my projects. Retrieval (BM25, written from scratch) runs in your browser over 15 method notes. Without a server it answers extractively, quoting the best sentences; connected to the FastAPI service it returns Claude's answer with citations.

Connect to a deployed API (optional)

Run docker run -p 8000:8000 -e ANTHROPIC_API_KEY bio-rag-assistant or deploy the container, then paste its URL. Stored only in this browser.
